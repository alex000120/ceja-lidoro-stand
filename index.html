Bienvenido

Usá tus manos frente a la cámara para controlar los videos.

Te pediremos permiso para usar la cámara.

Gestos

  • Puño cerrado Reproducir / pausar
  • Palma abierta quieta Reproducir / pausar
  • Deslizar palma ← / → Siguiente / anterior video
  • Pinza (pulgar + índice) Clic en el cursor, o arrastrar barras
  • Segunda mano: palma subir / bajar Volumen
  • Segunda mano: pulgar + índice separados Adelantar / retroceder
  • Corazón con ambas manos Foto recuerdo con cuenta regresiva

También podés usar el mouse o el teclado: espacio (reproducir), ← → (cambiar video), F (pantalla completa).
